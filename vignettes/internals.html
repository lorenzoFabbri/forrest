How forrest works

This vignette follows one data set through forrest(), calling the internal helpers directly to show what each step produces before anything is drawn. The helpers are not exported and are reached with :::; their interfaces may change between releases.

Design

forrest() is the only plotting function, and every layout is reached through its arguments, which name columns of the data as strings. The data stay tidy, one row per estimate. Visual structure such as section headers, indentation and blank rows is derived from grouping columns at draw time, so it never has to be written into the data.

All drawing uses base R graphics. The one dependency, tinyplot, sets up the plot region, so the axes and fonts follow tinyplot’s theming.

Section expansion

When section is set, forrest() first calls build_sections(), which returns the expanded data frame that is then drawn, along with three logical vectors marking the rows it inserted.

  lower          = "lower",
  upper          = "upper",
  label          = "study",
  is_summary     = "is_sum",
  weight         = "weight",
  section        = "region",
  subsection     = NULL,
  section_indent = TRUE,
  section_spacer = TRUE,

Passing section = "region" to forrest() performs this expansion and draws the result:

  meta,

  lower     = "lower",

  weight    = "weight",

Before expanding, forrest() copies the group and shape columns, and a per-row col vector, into private columns. Expansion rewrites the label column, and group may name that same column; the copies keep colours and legends tied to the original values, and inserted rows get none.

Values in header rows

section_cols fills chosen text columns on the header rows. forrest() translates its names, which are text-column headers, into the data columns those text columns display, and build_sections() writes into each one the first non-empty value of the source column among the section’s rows. Here the source column k_text holds the number of studies per section, and the displayed column k_row is empty on study rows.

meta$k_text <- c("k = 2", "", "k = 4", "", "", "", "k = 1")
meta$k_row  <- ""

exp_sc <- forrest:::build_sections(
  df             = meta,
  estimate       = "or",
  lower          = "lower",
  upper          = "upper",
  label          = "study",
  is_summary     = "is_sum",
  weight         = "weight",
  section        = "region",
  section_cols   = c(k_row = "k_text"),
  cols           = c("or_text", "k_row"),
  section_spacer = FALSE,
  section_indent = FALSE
)

Row types

After expansion every row is one of four types, and the type decides what is drawn. Structural rows are the inserted headers and spacers; header labels are bold. Reference rows are rows of the data whose estimate is NA; they show a plain label and no interval. Summary rows, flagged by is_summary, are drawn as diamonds. All other rows get a point and an interval. The classification for the expanded example:

df        <- expanded$df
est       <- as.numeric(df$or)
is_sum    <- as.logical(df$is_sum)
is_struct <- expanded$is_section_header |
             expanded$is_subsection_header |
             expanded$is_spacer
is_ref    <- is.na(est) & !is_sum & !is_struct
is_bold   <- (expanded$is_section_header | expanded$is_subsection_header) &
             nchar(trimws(df$study)) > 0L

data.frame(
  study     = df$study,
  is_sum    = is_sum,
  is_struct = is_struct,
  is_ref    = is_ref,
  is_bold   = is_bold,
  ci_drawn  = !is_sum & !is_struct & !is_ref
)

Summary diamonds

draw_diamond() draws each summary row as a polygon whose left and right tips are the confidence limits and whose top and bottom points sit above and below the estimate, 0.38 * cex rows from the centre. Limits beyond xlim are cut at the axis.

with_pool <- rbind(
  meta[, c("study", "region", "or", "lower", "upper", "is_sum")],
  data.frame(
    study  = "Pooled", region = "Overall",
    or     = 1.082, lower = 1.058, upper = 1.107,
    is_sum = TRUE
  )
)

forrest(
  with_pool,
  estimate   = "or",
  lower      = "lower",
  upper      = "upper",
  label      = "study",
  section    = "region",
  is_summary = "is_sum",
  log_scale  = TRUE,
  xlab       = "OR (95% CI)"

Dodging

compute_dodge_groups() numbers the bands that rows are drawn in. A new band starts at the first row, at every change of label, and at every structural row, so headers and spacers always have a band to themselves. Without dodge, each row is its own band.

dodge_ex <- data.frame(
  label  = rep(c("Asia", "Europe"), each = 2),
  method = rep(c("Cohort", "Case-control"), 2),
  or     = c(1.08, 1.05, 1.09, 1.07),
  lower  = c(1.04, 1.01, 1.05, 1.03),
  upper  = c(1.13, 1.09, 1.14, 1.11)
)

band <- forrest:::compute_dodge_groups(dodge_ex$label,
                                       rep(FALSE, nrow(dodge_ex)))

# Bands are one unit apart, top to bottom; rows in a band are spread
# symmetrically around its centre, `dodge` units apart.
n_band <- max(band)
centre <- (n_band + 1L) - band
k      <- tabulate(band)[band]
pos    <- ave(seq_along(band), band, FUN = seq_along)
y      <- centre + (pos - (k + 1) / 2) * 0.25

data.frame(dodge_ex[, c("label", "method")], band, y)
#>    label       method band     y
#> 1   Asia       Cohort    1 1.875
#> 2   Asia Case-control    1 2.125
#> 3 Europe       Cohort    2 0.875
#> 4 Europe Case-control    2 1.125

The two Asia rows sit at 2 ± 0.125 and the two Europe rows at 1 ± 0.125:

forrest(
  dodge_ex,
  estimate  = "or",
  lower     = "lower",
  upper     = "upper",
  label     = "label",
  group     = "method",
  dodge     = TRUE,
  log_scale = TRUE,
  xlab      = "OR (95% CI)"
)

Colours

group_colors() assigns colours to the distinct non-missing group values in order of appearance. By default it uses the Okabe-Ito palette from its second colour on, because the first is black and would be confused with the near-black of ungrouped rows. After eight groups the palette repeats.

forrest:::group_colors(c("Asia", "Europe", NA, "Latin America"))
#>          Asia        Europe Latin America 
#>     "#E69F00"     "#56B4E9"     "#009E73"

A col argument replaces the palette, matched by name or recycled in order:

forrest:::group_colors(c("Asia", "Europe"), c(Europe = "navy", Asia = "red"))
#>   Asia Europe 
#>  "red" "navy"

dat <- data.frame(
  label    = c("A", "B", "C"),
  estimate = c(0.2, -0.1, 0.4),
  lower    = c(0.0, -0.3, 0.2),
  upper    = c(0.4,  0.1, 0.6)
)

forrest(
  dat,
  estimate = "estimate",
  lower    = "lower",
  upper    = "upper",
  label    = "label",
  theme    = list(ref_col = "#e63946", ref_lty = 1L,
                  grid_col = "#eeeeee", stripe_col = "#fafafa"),
  stripe   = TRUE,
  xlab     = "Coefficient (95% CI)"
